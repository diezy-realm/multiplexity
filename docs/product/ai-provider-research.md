# Riset pengaturan AI Provider Multiplexity

Ditinjau 26 November 2026 untuk Multiplexity 0.3.0. Sumber primer mencakup kode T3 Code dan kontrak API vendor. Kredensial, inferensi, serta ketersediaan model untuk akun tertentu belum diuji.

## Alur T3 Code

- Settings → Providers menampilkan koneksi pada environment tempat agent berjalan. Pengguna menambahkan instance melalui **Add provider**, membuka katalog tambahan melalui **Show more**, dan memuat ulang status provider secara eksplisit. Refresh meminta model serta pembaruan sumber rahasia. [Panduan instalasi T3 Code](https://github.com/pingdotgg/t3code/blob/0df79074ad5f21478b616fe812746c0896ec90d7/docs/user/install.md#providers), [implementasi pengaturan provider](https://github.com/pingdotgg/t3code/blob/0df79074ad5f21478b616fe812746c0896ec90d7/apps/web/src/components/settings/ProviderSettingsPanel.tsx#L668-L679)
- Wizard provider bawaan memilih driver, mengisi label dan warna aksen, lalu menampilkan konfigurasi sesuai driver. Codex juga menawarkan jalur manual untuk instalasi yang sudah ada. Label dan warna merupakan metadata instance. ID instance dapat diturunkan dari label dan diperiksa terhadap ID yang sudah tersedia. [Pemilihan dan penyusunan ID](https://github.com/pingdotgg/t3code/blob/0df79074ad5f21478b616fe812746c0896ec90d7/apps/web/src/components/settings/AddProviderInstanceDialog.tsx#L218-L265), [identitas, konfigurasi, dan navigasi](https://github.com/pingdotgg/t3code/blob/0df79074ad5f21478b616fe812746c0896ec90d7/apps/web/src/components/settings/AddProviderInstanceDialog.tsx#L652-L793)
- T3 Code mendokumentasikan OpenRouter melalui Claude Code memakai direktori konfigurasi dan variabel environment per instance. OpenRouter juga menyediakan Chat Completions resmi, sehingga Multiplexity dapat menghubunginya langsung dari adapter HTTP yang sudah ada. [Panduan Claude di T3 Code](https://github.com/pingdotgg/t3code/blob/0df79074ad5f21478b616fe812746c0896ec90d7/docs/user/providers-claude.md#openrouter-and-local-routers), [OpenRouter Chat Completions](https://openrouter.ai/docs/api/api-reference/chat/create-a-chat-completion)

## Pemetaan ke Multiplexity

- Multiplexity menyimpan satu profil per ID provider. ID yang sudah tersimpan tetap digunakan oleh Chat dan Code Review. Profil berisi identitas, status aktif, model, dan hasil verifikasi terakhir. API key disimpan terenkripsi. [Penyimpanan koneksi](../../rust/app/src/ai/settings.rs), [pemilihan untuk review](../../rust/app/src/scm/review_ai.rs)
- Wizard dapat memisahkan pilihan provider, nama dan warna, lalu input yang spesifik untuk API key, base URL, executable, dan model. Bantuan konfigurasi mengarah ke sumber penerbit. Tombol pemeriksaan koneksi menguji draf sebelum simpan. Catalog refresh bekerja pada draf yang sama sehingga key atau endpoint baru dapat diperiksa langsung.
- Tampilkan status terpisah untuk konfigurasi tersimpan, executable ditemukan, kredensial ditemukan atau diterima, dan model yang tersedia. Daftar model dan status login lokal memeriksa kesiapan sesuai cakupannya. Keberhasilan inferensi membutuhkan uji chat pada model terpilih.
- OpenRouter, Groq, dan Grok menggunakan adapter Chat Completions yang sama. Pengujian memakai metadata model dan perintah status CLI. Untuk endpoint yang berbeda origin, formulir meminta key baru atau penghapusan key konfigurasi lama. [Adapter streaming](../../rust/app/src/ai/provider.rs), [probe](../../rust/app/src/ai/probe.rs), [wizard](../../src/components/AISettingsModal.tsx)
